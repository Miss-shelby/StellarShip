Core pillars

Everything you need
to go from code to chain.

Deployment Orchestration

Build and deploy multiple Soroban contracts in one command. StellarShip handles dependency ordering, graph-aware deploys, and upgrades across environments.

Git-Tracked Artifacts

Every deployment writes contract IDs and WASM hashes to stellarship.artifacts.json. Commit it. No hosted registry, no drift between teammates.

TypeScript Bindings

Auto-generate browser-ready, fully typed contract clients on every deploy. Import and call your Soroban functions from any frontend with zero boilerplate.

Wallet Adapters

Connect any Stellar-compatible wallet through a unified WalletAdapter interface. React hooks included. No manual signer setup required.

Atomic Safety

Artifact writes are atomic. Recovery scenarios are documented. Rollback is a single command. Your deployment state is always consistent and recoverable.

Full CI Integration

Built-in smoke tests, regression checks, and a ship ci command that mirrors your local dev flow in any CI environment. Ship with confidence.

Under the hood

Coordinate.
Deploy.
Connect.

StellarShip is the coordination layer on top of the official Stellar toolchain. Build, deploy, and invoke still delegate to Stellar CLI — you keep full access to the raw stack. StellarShip manages orchestration, artifact versioning, and the runtime bridge to your frontend.

01

Configure

Declare contracts, WASM paths, and network targets in stellarship.config.ts.

02

Build

ship build compiles your Rust contracts to WASM via Stellar CLI.

03

Deploy

ship deploy submits contracts, records IDs in artifacts, and triggers binding generation.

04

Connect

@stellarship/client wires artifacts + wallet to your frontend automatically.

Artifacts first

Your source of
truth. In Git.

No more copying contract IDs into .env files or losing track of which contract is deployed where. Every deployment writes a structured record — committed alongside your code.

🔒

Atomic writes

Artifact updates are atomic. A failed deploy never leaves you with a corrupt state.

🌐

Per-network keying

Testnet and mainnet IDs coexist in the same file. Never mix environments again.

🔄

Schema versioning

The artifact format is frozen and versioned. Migrations run automatically.

Monorepo

Three packages.
One mission.

@stellarship/cli

The Command Line

The ship binary. Everything you run in the terminal — from project init to production rollback.

  • init, build, deploy, upgrade
  • rollback, migrate, sync-env
  • doctor, smoke, regression, ci
  • identity, inspect, estimate
@stellarship/core

The Engine

Config loading, shell orchestration, Stellar CLI adapters, and the error catalog. The foundation everything builds on.

  • Config parsing & validation
  • Stellar CLI adapter layer
  • STELLARSHIP_* error codes
  • Deployment graph resolution
@stellarship/client

The Runtime

Browser and Node.js contract client, wallet adapters, and React hooks. Connects your frontend to deployed contracts with zero boilerplate.

  • Type-safe contract calls
  • Unified WalletAdapter API
  • React hooks included
  • Auto-resolves artifact IDs
